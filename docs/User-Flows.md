# Citylink User Flows

## 1. Signup

``` text
Splash
→ Welcome
→ Signup
→ Verification
→ Username
→ Password
→ Profile
→ City
→ Interests
→ Home
```

## 2. Login

``` text
Login
→ Credentials
→ Verification when required
→ Home
```

## 3. City Switching

``` text
Home
→ City Switcher
→ Search/Recent
→ Select city
→ Refresh city context
```

Rules: - No logout. - Same user identity. - Immediate context change.

## 4. Cross-City Posting

``` text
Create
→ Post
→ Select city
→ Write content
→ Publish
```

## 5. Create Community

``` text
Create
→ Community
→ Name
→ Description
→ City
→ Privacy
→ Rules
→ Verification settings
→ Create
```

## 7. Private Community

## 18. Flow Requirement

Every important flow must define: - Entry - Permission - Loading -
Empty - Error - Success - Cancellation - Back behavior - Notifications -
Security
