# Citylink Design Prompts

## Master UI Prompt

Design Citylink as a modern mobile-first local social platform combining
city discovery, communities, businesses, marketplace, services, jobs,
events and collective-demand Group Deals.

Direction: - Modern Local Social - Clean contemporary minimalism - Human
community feeling - Strong hierarchy - Subtle purposeful motion -
Trustworthy commerce - No generic SaaS appearance - No excessive
glassmorphism - No neon gradients - No purple/pink AI aesthetic - No
emoji-based interface icons

Follow `Design.md`.

## Consumer App Prompt

Prioritize: - Fast local discovery - City context - Communities - Group
Deals - Messaging - Profiles

Keep navigation predictable.

## Group Deal Prompt

Make these immediately visible: - Need - Location - Participants -
Target - Progress - Price state - Deadline - Primary action

## Community Prompt

Design communities as human social spaces, not dashboards.

## Business Prompt

Design for productivity: - Leads - Group Deal opportunities - Offers -
Services - Products - Messages - Reviews - Analytics

## Admin Prompt

Design for operations: - Tables - Filters - Reports - Verification -
Moderation - Disputes - Audit - Analytics

## Accessibility Prompt

Every generated screen must: - Have good contrast. - Have accessible
labels. - Support keyboard navigation on web. - Use comfortable touch
targets. - Support reduced motion. - Handle text scaling. - Avoid
color-only communication. - Handle multilingual text.

## AI Agent UI Workflow

Before generating a new screen: 1. Read Design.md. 2. Read Screens.md.
3. Read User-Flows.md. 4. Find reusable components. 5. Use existing
tokens. 6. Do not invent navigation. 7. Add loading/empty/error states.
8. Check responsive behavior.
